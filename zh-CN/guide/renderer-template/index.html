RendererTemplate 扩展表单项 ​

概述 ​

FormItemRendererTemplate 是一个强大的表单扩展机制，它允许你自定义表单项的渲染方式。通过这个功能，你可以：

  • 创建自定义的表单控件
  • 复用已有的组件
  • 实现特殊的业务逻辑
  • 扩展表单的功能范围

基础使用 ​

在 FormItems 表单项 中，templateType 属性决定了表单项的渲染组件。通过 VkfFormItemRendererTemplate 组件，我们可以自定义这个渲染过程。

基本语法 ​

html
<VkfForm>
  <template #rendererTemplate>
    <VkfFormItemRendererTemplate type="YOUR_TEMPLATE_TYPE">
      <!-- 自定义的表单控件内容 -->
    </VkfFormItemRendererTemplate>
  </template>
</VkfForm>

工作原理 ​

本质上，这种设计遵循策略模式：

  1. 每个 VkfFormItemRendererTemplate 定义一个特定的 type
  2. 表单项通过 templateType 匹配对应的模板
  3. 匹配成功后渲染模板中的内容

插槽数据 ​

FormItemRendererTemplate 插槽 ​

在自定义模板时，你需要使用 formItem 中提供的数据来实现组件间的通信。默认插槽提供了以下关键参数：

参数名说明类型
raw原始的渲染数据RendererTreeData
props当前表单项数据（排除内部字段）Omit<RendererTreeData, InternalField>
value对应的表单数据值any
input更新表单数据的方法(v: any) => void
完整的插槽参数定义
ts
type RendererTreeData = __VkfFormItemRenderer.RendererTreeData

// 内置字段
type InternalField = 'templateType' | 'templateIf' | 'informationProps' | 'templateProps' | 'inputEffect'

export interface DefaultSlotArguments {
  raw: RendererTreeData
  templateIf: (e: NormalObject) => boolean 
  props: Omit<RendererTreeData, InternalField>
  informationProps: NormalObject
  k: (string|number)[]
  Renderer: typeof VkfFormItemRenderer
  value?: never
  input?: (v: any) => void
  inputEffect?: (v: any, e: InputEffectContext) => void
  getDataValue: (key: MaybeArray<number | string>) => any
  emitSetData: (e: SetDataEvent) => void
}

扩展规范 ​

为了保持与 ElementPlus Form 的一致性和兼容性，扩展表单项时需要遵循以下规范：

1. 使用 FormItem 包装器 ​

始终使用 FormItem 组件包装自定义输入控件：

vue
<VkfFormItem v-bind="formItemBindProps">   
  <ElInput v-bind="inputProps">
    <!-- 输入控件内容 -->
  </ElInput>
</VkfFormItem>

2. 类型定义 ​

为了类型安全，需要正确暴露 Source 类型：

ts
import { BasicSource } from '@vunk/form'
import type { VueComponentPropsType } from '@vunk/core'

export interface Source<P = string> 
extends VueComponentPropsType<typeof VkfInput>, BasicSource { 
  prop?: P,
  templateType: 'VkfInput',
}

3. 只读状态管理 ​

使用 useComputedReadonly 统一管理只读状态：

ts
import { useComputedReadonly } from '@vunk/form/composables'

export default {
  props: {
    readonly: {
      type: Boolean,
      default: undefined, // 未定义时使用 Form 的 readonly
    }
  },
  setup(props) {
    const readonly = useComputedReadonly(props)
    return { readonly }
  }
}

Component 类型 ​

Form 组件提供了一个特殊的 templateType: component，它的功能类似于 Vue 的动态组件 <component>，用于直接渲染自定义组件：

最佳实践 ​

添加模板 ​

html
  <VkfFormItemRendererTemplate type="VkfInput">
    <template
      #default="{ 
        props, value, input
      }"
    >
      <VkfInput 
        :model-value="value"
        v-bind="props"
        @update:model-value="input"
      ></VkfInput>
    </template>
  </VkfFormItemRendererTemplate>

扩展类型 ​

ts
import { BasicSource } from '@vunk/form'
import type { VueComponentPropsType } from '@vunk/core'

export interface InputSource<P = string> 
extends VueComponentPropsType<typeof VkfInput>, BasicSource { 
  prop?: P,
  templateType: 'VkfInput',
}

// 扩展 FormItem 类型
export type FormItem<P = string> = 
  __VkfForm.FormItem<P> 
  | InputSource<P> // 这里假设 VkfInput 是一个扩展表单项
Input组件示例
vue
<script lang="ts">
import { props, emits } from './ctx'
import { defineComponent } from 'vue'
import { ElInput } from 'element-plus'
import { VkfFormItem, _VkfFormItemCtx } from '@vunk-form/components/form-item'
import { createInputBindProps, createInputOnEmits } from '@vunk-form/shared/element-plus'
import { useComputedReadonly } from '@vunk-form/composables'

export default defineComponent({
  name: 'VkfInput',
  components: {
    ElInput, 
    VkfFormItem,
  },
  props,
  emits,
  setup (props, { emit }) {
    const inputBindProps = createInputBindProps(props, ['readonly'])
    const inputOnEmits = createInputOnEmits(emit)
    const formItemBindProps = _VkfFormItemCtx.createBindProps(props)
    const readonly = useComputedReadonly(props)

    return {
      inputBindProps,
      formItemBindProps,
      readonly,
      inputOnEmits,
    }
  },
})
</script>

<template>
  <VkfFormItem v-bind="formItemBindProps">   
    <ElInput
      v-bind="inputBindProps"
      :readonly="readonly"
      v-on="inputOnEmits"
    >
      <slot></slot>
    </ElInput>
    <slot name="formItem"></slot>
  </VkfFormItem>
</template>

自定义表单组件的完整接入流程 ​

把一个业务组件注册为可复用的 templateType（如 SkModelParamsTrigger、SkInputSwitchableModels）需要以下 4 步：

1. Core 组件 ​

src/index.vue 只负责 UI 与交互，通过 props/emits 与外部通信：

vue
<script setup lang="ts">
import { props as dProps, emits } from './ctx'
const props = defineProps(dProps)
const emit = defineEmits(emits)
</script>

<template>...</template>

2. template.vue 注册渲染 ​

用 VkfFormItemRendererTemplate 声明 type，插槽里通过 value/input/emitSetData/getDataValue 与表单数据桥接：

vue
<script setup lang="ts">
import { VkfFormItemRendererTemplate } from '@vunk/form'
import Core from './index.vue'
</script>

<template>
  <VkfFormItemRendererTemplate type="SkModelParamsTrigger">
    <template #default="{ props, value, input }">
      <Core v-bind="props" :model-value="value" @update:model-value="input" />
    </template>
  </VkfFormItemRendererTemplate>
</template>

3. 导出 Source 类型 ​

src/types.ts 导出 Source<P>，供 VkfFormItemRenderer / VkfInputCollection.Column 推导 templateType 与 templateProps：

ts
import type { VueComponentPropsType } from '@vunk/core'
import type Core from './index.vue'

export interface Source<P = string> extends
  Omit<VueComponentPropsType<typeof Core>, 'onUpdate:modelValue' | 'modelValue' | 'templateType'> {
  templateType: 'SkModelParamsTrigger'
  prop: P
}

4. 接入 FormItem 联合类型并注册模板 ​

在业务侧 form-templates 的 FormItem 联合类型中加入 Source，并在模板树中注册：

ts
// types.ts
import type { __SkModelParamsTrigger } from '.../model-params-trigger'

export type FormItem<T = string> =
  | __VkfTemplatesDefault.CoreSource<T>
  | __SkModelParamsTrigger.Source<T>
  // ...
html
<!-- index.vue -->
<SkModelParamsTriggerTemplate></SkModelParamsTriggerTemplate>

要点

FormItem 联合类型是 VkfInputCollection.Column<R, SourceType> 第二个泛型的来源；只有加入联合类型，templateType 字符串才能通过类型检查。

跨字段引用（getDataValue / emitSetData） ​

模板插槽里的 getDataValue(prop) 与 emitSetData({ k, v }) 使用完整 prop 路径（含数组下标）。

在 VkfInputCollection 的列中，若某列需要读写同一行的其他字段，用 createTemplateProps 动态生成带 $index 的路径：

ts
{
  templateType: 'SkModelParamsTrigger',
  prop: 'model_params_setting',
  createTemplateProps: (e, formItemProps) => ({
    // formItemProps.prop === [collectionProp, $index, 'model_params_setting']
    modelIdProp: [...(formItemProps.prop as any[]).slice(0, -1), 'model_id'],
  }),
}

随后在 template.vue 里 getDataValue(props.modelIdProp) 即可响应式读到同一行的 model_id，而不是渲染时的静态快照。

templateProps vs createTemplateProps ​

机制作用位置求值时机用途
templateProps（对象/函数）VkfFormItemRenderer对象静态；函数每次渲染用 rendererData 调用给模板传静态 props，或基于表单数据动态算 props
createTemplatePropsVkfInputCollection.Column渲染 cell 时执行一次基于当前行（e.row）与 formItemProps 生成 source 字段，常用于生成带 $index 的 prop 路径
