InputEffect 副作用 ​

表单项的副作用功能允许您在表单项的值发生改变时，执行一些副操作，比如重置其他字段的值、更新校验规则或触发数据联动等。

API ​

InputEffect 函数接收两个参数：

typescript
  /**
   * @description 当 input 触发时, 产生的副作用
   */
  inputEffect?: (
    value: any,  // input 触发的值
    context: InputEffectContext
  ) =>  void

interface InputEffectContext extends __VkfFormItemRendererTemplate.DefaultSlotArguments  {
  parentProp: Array<string | number>
}

使用场景 ​

  • 字段值联动：当一个字段的值变化时，需要更新其他相关字段的值
  • 数据重置：在特定条件下重置一组相关字段的值

注意事项 ​

  • 如果需要更新多个字段，可以多次调用 emitSetData , 这样可以保持代码的清晰度

  • inputEffect 是在 DefaultSlotArguments input 触发后执行的副操作, 未使用 input, inputEffect 将不会被触发。扩展表单项时, 如果你无法直接使用 input 时, 可以考虑手动调用 inputEffect

    ts
    handleChange = (v) => {      // 特殊的场景
  inputEffect?.(v, {
    ...defaultSlotArguments,
    parentProp: [c.prop].flat(Infinity).slice(0, -1),
  })
},

  • 我们不建议在 inputEffect 中做异步操作, 除非你明确知道你在做什么
