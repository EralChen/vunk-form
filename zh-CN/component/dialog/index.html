Dialog ​

一个更适合表单场景的 Dialog 组件，基于 ElDialog 封装。

特性 ​

  • 🎯 表单优化 - 内置 FormsProvider，可直接在 Dialog 中使用表单组件
  • ✅ 验证支持 - footer 插槽提供 validate 方法，便于表单验证
  • 🔄 自动重置 - Dialog 打开时自动重置表单验证状态
  • 🎨 默认配置 - draggable: true、closeOnClickModal: false 更符合表单使用场景
  • 📦 完全兼容 - 继承 ElDialog 所有属性和事件

基础用法 ​

在 Dialog 中使用表单，通过 footer 插槽的 validate 方法进行表单验证。

RTL 支持 ​

Dialog 组件支持 RTL（从右到左）布局，当父容器设置 dir="rtl" 时会自动适配：

  • 关闭按钮位置调整到左侧
  • 底部按钮对齐方式反转
  • 内部表单组件自动适配 RTL

Footer Slot 参数 ​

参数类型说明
formsArrayDialog 内所有表单的实例数组
validate() => Promise<boolean[]>验证所有表单的方法，返回验证结果数组
elFormRef<FormInstance>第一个表单的 ElForm 实例引用

使用示例 ​

表单验证 ​

vue
<template>
  <VkfDialog v-model="visible" title="编辑信息">
    <VkfForm
      :data="formData"
      :form-items="formItems"
      @set-data="setData(formData, $event)"
    />
    
    <template #footer="{ validate }">
      <ElButton @click="visible = false">取消</ElButton>
      <ElButton type="primary" @click="handleSubmit(validate)">
        确定
      </ElButton>
    </template>
  </VkfDialog>
</template>

<script setup lang="ts">
import { VkfDialog } from '@vunk-form/components/dialog'
import { VkfForm } from '@vunk/form'
import { setData } from '@vunk/core'
import { validateCatch } from '@vunk-form/shared/form'

const visible = ref(false)
const formData = reactive({ name: '' })

function handleSubmit(validate: () => Promise<any>) {
  validate().then(() => {
    // 验证通过，提交数据
    visible.value = false
  }).catch(validateCatch)
}
</script>

注意事项 ​

  1. Dialog 打开时会自动调用内部表单的 clearValidate() 方法重置验证状态
  2. 使用 v-model 控制 Dialog 的显示/隐藏
  3. footer 插槽的 validate 方法返回 Promise，建议使用 .then()/.catch() 处理验证结果
  4. 默认关闭了点击遮罩关闭功能，避免用户误操作丢失表单数据
