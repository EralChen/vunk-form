Collapse 折叠面板 ​

ElCollapse / ElCollapseItem Wrapper

VkfCollapse 与 VkfCollapseItem 在原生 ElCollapse / ElCollapseItem 之上增加了校验错误自动展开能力：当 VkfFormItem 处于折叠面板内部且校验失败时，会自动展开其所在面板，避免报错信息被折叠隐藏。

校验错误自动展开折叠面板 ​

当 VkfFormItem 处于折叠面板内部时，若该表单项校验失败，会自动展开其所在的面板，避免报错信息被折叠隐藏。

机制是去中心化的：VkfCollapseItem 注入原生 ElCollapse 的 collapseContextKey 上下文（含 activeNames、handleItemClick、accordion），并用自身 injection key 把「面板 name + 该上下文」provide 给后代；VkfFormItem 注入此上下文，在 VkfForm 完成 validate() 后监听 afterValidate（携带 invalidFields），只把自身 prop 命中 invalidFields 的面板展开——仅在显式调用 form.validate() 时触发，输入框的实时校验不会触发展开。

  • 手风琴（accordion）：activeNames 内部为单元素数组（对外 v-model 是 string）。提交校验后，仅 invalidFields 中第一个失败字段（即 Object.keys(invalidFields)[0]，对应 DOM / 注册顺序中第一个报错的 VkfFormItem）所在的面板会被展开；其余报错面板不会自动展开。由于 accordion 同一时刻只能展开一个面板，展开该面板会关闭当前其它已展开的面板——包括用户手动点开、但本身无报错的面板。
  • 非手风琴：activeNames 为数组，所有校验失败的面板都会被加入展开列表（幂等，多个可同时展开），不会关闭任何已展开面板。

VkfCollapse 设为 accordion 时同一时刻只能展开一个面板。若多个表单项同时校验失败，VkfCollapse 确定性地展开校验顺序中第一个报错的面板（即 invalidFields 的第一个字段，而非最后一个）。需注意：accordion 模式下展开该面板会关闭其它已展开面板，因此可能覆盖用户手动点开的无报错面板。非 accordion 模式下所有报错面板会同时展开。

手风琴：展开第一个报错面板 ​

accordion 模式下，提交时若多项未填，折叠面板会确定性地展开校验顺序中第一个报错的面板；其余报错面板保持折叠，且已展开的其他面板（含手动点开的）会被关闭。

非 accordion：所有报错面板同时展开 ​

非 accordion 模式下，VkfCollapse 不做「第一个报错面板胜出」的协调，而是确保每一个校验失败的面板都展开，方便一眼看到全部错误。

Collapse Props ​

proptypedefaultdescription
ElCollapse 全部 props--继承 ElCollapse 所有属性
modelValuestring | number | Array<string | number>-受控展开项（与 ElCollapse 一致：accordion 下为 string，其余为 Array）
accordionbooleanfalse是否手风琴模式

VkfCollapse 是 ElCollapse 的薄封装，并通过 SetAttrs 把 accordion 注入原生 collapseContextKey；VkfCollapseItem 向后代暴露该上下文（含 activeNames）与面板 name，由 VkfFormItem 监听祖先 VkfForm 的 afterValidate 自行展开。

Collapse Slots ​

namedescription
default插槽，放置 VkfCollapseItem 等折叠面板内容（透传至 ElCollapse 的默认插槽）

CollapseItem Slots ​

namescopeddescription
default-面板内容，透传至 ElCollapseItem 的默认插槽
title{ isActive: boolean }自定义面板标题，透传至 ElCollapseItem 的 title 插槽
icon{ isActive: boolean }自定义展开箭头图标，透传至 ElCollapseItem 的 icon 插槽

使用注意 ​

  1. 必须将 VkfCollapse 放在 VkfForm 内部，才能接收到 validate() 完成信号并触发自动展开。
  2. 自动展开仅在调用 VkfForm 的 validate() 时触发；输入时的实时校验不会展开面板。
  3. VkfCollapseItem 的 name 若省略会自动生成，但建议显式指定以保证注册与错误上报的稳定对应。
